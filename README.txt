TALYA & GEGE — BILINGUAL CVL WEBSITE

Included:
- index.html: editorial / school-notebook inspired French-English website.
- poster-photo.jpg: extracted from the supplied poster PDF and used by the site.

PUBLISH:
1. Create a public GitHub repository (e.g. talya-gege-cvl).
2. Upload index.html and poster-photo.jpg.
3. Open Settings → Pages; choose Deploy from a branch, branch main, folder /(root), Save.
4. After publication, the address will look like https://YOUR-USERNAME.github.io/talya-gege-cvl/
5. Keep the same account and repository to keep the URL stable. To update the site, replace the files and commit.

The site is designed to be readable on phones. Test the live URL before printing a QR code.
